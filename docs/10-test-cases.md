# Набор тест кейсов

## Создание заявки

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-01 | Валидная заявка с новым ключом | `201`, одна заявка, одна запись истории, одно outbox-событие |
| TC-02 | Нет `Idempotency-Key` | `400`, данные не сохранены |
| TC-03 | Тот же ключ и то же тело | Возвращен прежний результат, новая заявка не создана |
| TC-04 | Тот же ключ и другое тело | `409 IDEMPOTENCY_KEY_REUSED` |
| TC-05 | Повторный `external_request_id` | `409 DUPLICATE_EXTERNAL_ID` |
| TC-06 | Описание состоит из пробелов | `422 VALIDATION_ERROR`, указано поле `description` |
| TC-07 | Неизвестная категория | `422 VALIDATION_ERROR` |
| TC-08 | Аварийная заявка | `201`, приоритет сохранен как `critical` |
| TC-09 | Квартира и этаж отсутствуют для общей территории | `201`, необязательные поля равны `null` |
| TC-10 | URL вложения использует `http` | `422 VALIDATION_ERROR` |

## Назначение и статусы

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-11 | Назначение активного мастера на `CREATED` | `200`, статус `ASSIGNED`, версия увеличена |
| TC-12 | Назначение неактивного мастера | `422 MASTER_INACTIVE` |
| TC-13 | Изменение с устаревшим `If-Match` | `409 VERSION_CONFLICT` |
| TC-14 | Переход `ASSIGNED → IN_PROGRESS` | `200`, история и outbox обновлены |
| TC-15 | Переход `CREATED → COMPLETED` | `409 INVALID_STATUS_TRANSITION` |
| TC-16 | Изменение терминального статуса | `409 INVALID_STATUS_TRANSITION` |
| TC-17 | Мастер меняет чужую заявку | `403 FORBIDDEN` |
| TC-18 | Неизвестный ID заявки | `404 REQUEST_NOT_FOUND` |

## Надежность и выдача

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-19 | Сервис уведомлений отвечает `503` | Бизнес-операция сохранена; событие запланировано на повтор |
| TC-20 | Получатель уже видел `event_id` | Повтор не создает второе уведомление |
| TC-21 | Фильтр по статусу и приоритету | Все записи соответствуют обоим фильтрам |
| TC-22 | Запрошено более 100 записей | `400 BAD_REQUEST`, данные не выдаются |
| TC-23 | Две страницы при одинаковом времени создания | Стабильный порядок обеспечен дополнительной сортировкой по `id` |

## Проверки безопасности

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| TC-24 | Нет bearer-токена | `401 UNAUTHORIZED` |
| TC-25 | Роль жителя вызывает назначение мастера | `403 FORBIDDEN` |
| TC-26 | В описании переданы управляющие символы | Значение безопасно обрабатывается, логи не повреждаются |
| TC-27 | Входной запрос содержит лишнее поле | `422 VALIDATION_ERROR` из-за `additionalProperties: false` |
