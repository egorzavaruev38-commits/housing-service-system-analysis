# Интеграции и надежность

## Синхронное API

Клиентские приложения вызывают REST API по HTTPS. Каждый изменяющий запрос содержит `X-Correlation-ID`; создание дополнительно содержит `Idempotency-Key`. API выполняет валидацию, авторизацию и бизнес-правила до фиксации транзакции.

## Асинхронные уведомления

Сохранение заявки и отправка уведомления не объединяются в распределенную транзакцию. Вместо прямого вызова в бизнес-транзакции создается запись `outbox_event`.

1. API сохраняет заявку и событие в одной транзакции.
2. Worker читает события со статусом `NEW` или готовые к повтору.
3. Worker передает событие сервису уведомлений.
4. После подтверждения событие становится `SENT`.
5. При временной ошибке увеличивается `retry_count` и рассчитывается `next_attempt_at`.
6. После лимита повторов событие становится `FAILED`, а мониторинг уведомляет поддержку.

Доставка предполагает модель at-least-once. Получатель обязан дедуплицировать события по `event_id`.

## Политика повторов

- повторяются timeout, сетевые ошибки и ответы `429`, `502`, `503`, `504`;
- ошибки контракта `400` и `422` не повторяются автоматически;
- задержка: 10 секунд, 1 минута, 5 минут, 30 минут с небольшим jitter;
- максимальное число автоматических попыток — 5;
- ручной повтор сохраняет исходный `event_id` и создает запись аудита.

## Timeout

- соединение — 1 секунда;
- полный запрос к сервису уведомлений — 3 секунды;
- timeout не считается доказательством отсутствия обработки у получателя, поэтому повтор использует тот же `event_id`.

## Модель события

```json
{
  "event_id": "evt-1002",
  "event_type": "request.status_changed",
  "occurred_at": "2026-09-05T15:20:00Z",
  "correlation_id": "corr-1002",
  "aggregate_id": 2,
  "payload": {
    "previous_status": "ASSIGNED",
    "new_status": "IN_PROGRESS",
    "version": 3
  }
}
```

## Ошибки и наблюдаемость

Клиент получает стабильный машинный код ошибки и человекочитаемое сообщение. Технические детали и stack trace наружу не возвращаются. По `correlation_id` поддержка связывает входной запрос, транзакцию, outbox-событие и попытки доставки.
